# gransim — 수직 가진 과립계 DEM 시뮬레이터 + 충돌음 합성

폐쇄 용기 안 입자의 **개수를 충돌음만으로 추정하는 머신러닝**에 쓸 학습 데이터를 만드는 물리 시뮬레이터입니다.
물성(반발계수, 마찰, 밀도 등)을 연속적으로 바꾸면서, 다른 조건은 완전히 고정한 채로, 정확한 라벨이 붙은 음향 데이터를 생성하는 것이 목표입니다.

> 진행 상황: **1단계(동역학 엔진), 2단계(충돌 이벤트·벽 힘 시계열) 완료.** 음향 합성, 스윕, 분석 도구는 이후 단계에서 추가됩니다.

## 설치

```bash
pip install -e ".[dev]"
```

Python 3.11 이상, 의존성은 NumPy, Numba, SciPy, pydantic, PyYAML, matplotlib.

## 빠른 실행

```bash
gransim info configs/experiment_replica.yaml                 # 무차원수·경고만 출력
gransim run configs/quick_test.yaml --out runs/quick         # 단일 실행
gransim run configs/experiment_replica.yaml --out runs/a --set particles.count=200 --set excitation.rpm=600
gransim benchmark --n 300 --duration 1.0                     # 속도 측정
```

`run`의 결과 폴더:

| 파일 | 내용 |
|---|---|
| `config_snapshot.yaml` | 사용된 설정 전체 + 유도된 무차원수 (재현용) |
| `diagnostics.npz` | 시계열(아래) + 입자 반지름·질량, 최종 상태 |
| `summary.json` | 실행 시간, 무차원수 |
| `events.npz` | 충돌 이벤트 표 (아래), 분류 임계값 `param_*`, 기록 구간 `record_window` |
| `wall_force.npz` | 벽별 법선력 시계열 `force[6, n]` [N], `fs` [Hz], 시작 시각 `t0` [s], `walls` |
| `trajectory.npz` | (`output.save_trajectory: true`일 때) 시각 `t`, 용기 변위 `zc`, 입자 위치 `x[frame, i, xyz]` (실험실 좌표) |

모든 시각은 **가진 시작 시점 기준**입니다. 기록 구간은 `[discard_time, discard_time + record_time]`입니다.

### 충돌 이벤트 (`events.npz`)

접촉 하나(시작부터 끝까지)가 이벤트 하나입니다. 매 스텝의 힘을 덤프하지 않습니다.

| 필드 | 의미 |
|---|---|
| `t_start`, `t_peak`, `t_end` | 접촉 시작, 최대 법선력 시각, 접촉이 사라진 첫 시각 [s] |
| `kind` | 0 = 입자-입자(pp), 1 = 입자-벽(pw) |
| `contact_type` | 0 = `impact`(충격성), 1 = `sustained`(지속) |
| `n_merged` | 병합된 떨림 접촉 조각 수 (1 = 병합 없음) |
| `wall_id` | 0 바닥, 1 천장, 2 x−, 3 x+, 4 y−, 5 y+ (pp는 −1) |
| `i`, `j` | 입자 인덱스 (벽이면 `j = −1`) |
| `v_rel_n` | 첫 접촉 시 법선 접근 속도 [m/s] |
| `J_n`, `J_t` | 법선 충격량 ∫F_n dt, 접선 충격량 ∫\|F_t\| dt [N·s] |
| `F_peak`, `duration` | 최대 법선력 [N], 지속 시간 [s] |
| `x`, `y`, `z` | 최대 힘 시점의 접촉점 (용기 좌표계) [m] |
| `m_eff`, `R_eff` | 유효 질량 [kg], 유효 반지름 [m] (음향용 접촉 시간 계산에 사용) |
| `phase` | 접촉 시작 시 가진 위상 (0~1) |
| `flags` | 비트 1: 기록 시작 전에 시작된 접촉(충격량은 기록 시작부터), 비트 2: 기록 끝에 아직 열려 있던 접촉 |

- **분류**:
  - `impact`는 첫 접촉 속도가 `v_impact` 이상이고 지속 시간이 `duration_max` 이하인 접촉입니다. 나머지는 `sustained`입니다.
  - 기본값은 `v_impact = 0.1·sqrt(2 g d)`(≈ 0.034 m/s), `duration_max = 3 × 이체 접촉 시간`입니다.
  - 지속 접촉은 음향에서 펄스로 만들지 않습니다. 그 힘의 변동은 벽 힘 시계열이 담습니다.
- **떨림 접촉 병합**: 같은 쌍이 `merge_gap`(기본: 이체 접촉 시간) 안에 다시 붙고, 그때 접근 속도가 `v_impact` 미만이면 같은 이벤트로 합칩니다.
- **임계값 민감도**: `events.tracker.classification_sensitivity`로 확인합니다. 기본 조건에서는 두 임계값을 0.5~4배로 바꿔도 impact가 차지하는 충격량 비율이 98~100%로 거의 변하지 않습니다.
- **조건 (b) 점검**: `collision_interval_check`는 한 입자의 연속 충돌 간격 중앙값을 접촉 시간과 비교합니다. 10배 미만이면 경고합니다.

### 벽 힘 시계열 (`wall_force.npz`)

6개 벽이 받는 법선력 합을 `events.wall_force_rate`(기본 22050 Hz)로 저장합니다.
동역학 스텝보다 성긴 간격이므로 **구간 평균(충격량 / 구간 길이)**으로 저장해 충격량을 정확히 보존합니다.
벽별 시계열의 시간 적분은 같은 벽 이벤트들의 `J_n` 합과 정확히 같습니다(테스트로 확인).

`diagnostics.npz` 시계열 (가진 시작 시점 기준 시간축, SI 단위):
`t, zc, ke_trans, ke_rot, pe, e_n, e_t, w_in, d_n, d_t, d_corr, w_k, mean_height, n_pp, n_pw`.
에너지 항목의 의미는 아래 "에너지 수지" 참조.

## 설정 (YAML)

모든 값은 SI 단위입니다. 파이썬에서도 같은 구조로 지정할 수 있습니다:
`SimConfig(particles={"count": 150}, excitation={"rpm": 600})`. 알 수 없는 키나 잘못된 값은 로드 시 에러가 납니다.

| 섹션.키 | 의미 | 기본값 |
|---|---|---|
| `container.size` | 용기 내부 치수 (Lx, Ly, Lz) [m] | (0.05, 0.05, 0.07) |
| `container.mass`, `wall_thickness` | 용기 질량 [kg], 벽 두께 [m] (메타데이터·질량비) | 0.070, 0.003 |
| `container.material` | 벽 탄성률 E [Pa], 푸아송비 | 아크릴 3.2 GPa, 0.37 |
| `particles.count` | 입자 수 N (라벨) | 100 |
| `particles.diameter`, `mass` | 지름 [m], 개당 질량 [kg] | 0.006, 1.2e-4 |
| `particles.diameter_rel_std` | 다분산 지름 상대 표준편차 (0 = 단분산) | 0 |
| `particles.material` | 입자 E [Pa], 푸아송비 | ABS 계열 2.3 GPa, 0.35 |
| `particles.init` | 초기 배치: `random`(무작위 순차 배치 후 정착 → 무질서 충전) / `lattice` | random |
| `contact.model` | `linear`(완화 강성, 대량 생성용) / `hertz`(검증용) | linear |
| `contact.contact_time` | linear: 이체 비감쇠 접촉 시간 [s] → 강성 k 유도 | 2e-4 |
| `contact.modulus_scale` | hertz: 실제 E에 곱하는 배율 (1 = 실제 강성) | 1.0 |
| `contact.restitution_pp/pw` | 입자-입자 / 입자-벽 반발계수 | 0.8 |
| `contact.friction_pp/pw` | 쿨롱 마찰계수 | 0.3 |
| `contact.rotation` | 회전 자유도 on/off | true |
| `excitation.mode` | `fixed_amplitude`(실험 재현: A 고정, f만 변수) / `free` | fixed_amplitude |
| `excitation.amplitude, frequency, rpm, gamma` | A [m], f [Hz], rpm, Γ | A = 0.0134 |
| `excitation.ramp_time` | 가진 시작 시 진폭을 부드럽게 올리는 시간 [s] | 0.2 |
| `time.dt` | 적분 스텝 [s] (비우면 자동) | 자동 |
| `time.settle_time` | 가진 전 정착 시간 (출력 제외) [s] | 0.5 |
| `time.discard_time`, `record_time` | 가진 후 버리는 시간, 기록 시간 [s] | 1.0, 5.0 |
| `events.v_impact`, `duration_max`, `merge_gap` | 이벤트 분류·병합 임계값 (비우면 자동) | 자동 |
| `events.wall_force_rate` | 벽 힘 시계열 표본화 주파수 [Hz] | 22050 |

`fixed_amplitude` 모드에서 `gamma`를 지정하면 에러입니다. 크랭크 구동은 진폭이 고정이라 Γ ∝ f²로 묶이므로, Γ와 f를 독립으로 바꾸면 실험에 없는 조건이 만들어지기 때문입니다.
`free` 모드에서는 (A, f 또는 rpm, Γ) 중 정확히 두 개를 지정합니다.

## 동역학 모델 (1단계)

- **입자**: 3차원 구. 지름·질량은 입자별 배열이라 다분산 확장이 가능합니다. 상태는 위치, 속도, 각속도입니다.
- **법선 접촉**:
  - 선형 스프링-댐퍼 `F_n = k δ + c δ̇`, 또는 Hertz `F_n = k_h δ^1.5 + c_h δ^0.25 δ̇`.
  - 인장력은 0으로 자릅니다.
- **접선 접촉**:
  - 접선 스프링 변위 ξ를 접촉마다 기억하는 쿨롱 상한 스프링-댐퍼(Cundall–Strack)입니다.
  - 토크의 지렛대 팔은 실제 접촉점까지의 거리(R − δ/2)라서 각운동량이 정확히 보존됩니다.
- **벽**: 용기 전체가 `z_c(t) = A·s(t)·sin(2πft)`로 움직입니다. `s(t)`는 시작 램프입니다.
  - 여섯 면이 모두 같이 움직이고, **벽 속도를 상대 속도에 반영**합니다.
  - 위상 0은 용기가 평균 위치를 위로 지나는 순간입니다.
- **중력**: −z 방향.
- **이웃 탐색**: 용기 좌표계의 균일 격자 셀 리스트를 씁니다(셀 크기 ≥ 최대 지름).
- **적분**: 반암시적(심플렉틱) 오일러입니다. 핵심 루프는 Numba로 컴파일합니다.

### 반발계수 → 감쇠 계수 (조회표)

인장력을 자르면 교과서 환산식 `ζ = −ln e / sqrt(π² + ln² e)`가 틀립니다. 낮은 e일수록 크게 틀립니다.
그래서 **엔진과 같은 적분기로 단일 충돌을 수치 적분해 만든 조회표**에서 감쇠를 역산합니다.
조회표는 무차원이라 질량·강성과 무관하게 하나로 충분하고, Hertz(Tsuji 감쇠)도 같은 방식입니다.
입자-입자와 입자-벽 반발계수는 독립적으로 지정합니다.

### 시간 스텝 자동 선택

기본값은 `dt = 접촉시간 / 20`입니다. 여기에 한 가지 조건을 더 봅니다.

- **배경**: 접촉은 스텝 사이 임의의 순간에 감지되기 때문에, 충돌 하나하나의 반발계수가 평균 주위로 흩어집니다. 평균은 정확하고 흩어짐도 평균 0이지만, e가 낮을수록(감쇠가 클수록) 커집니다. dt = 접촉시간/20일 때 e = 0.3이면 ±8%, e = 0.9이면 ±0.6%입니다.
- **규칙**: 이 흩어짐이 `time.max_restitution_scatter`(기본 5%)를 넘으면 dt를 자동으로 반으로 줄입니다.
- **결과**: 일반적인 e(≈ 0.8)에서는 비용이 그대로이고, 낮은 e에서만 스텝이 촘촘해집니다.

### 에너지 수지

실험실 좌표에서 다음 관계가 성립해야 합니다.

```
Δ(KE_병진 + KE_회전 + PE_중력 + E_탄성) = W_in + W_k − (D_n + D_t + D_corr)
```

| 항 | 의미 |
|---|---|
| `W_in` | 움직이는 벽이 한 일 (Σ F·U_wall dt) |
| `D_n` | 법선 감쇠·인장력 절단에 의한 소산 |
| `D_t` | 접선 점성 소산 + 미끄럼 마찰 소산 |
| `D_corr` | 소산력의 일을 스텝 중간 속도로 보정한 항 |
| `W_k` | Hertz 모델에서 겹침에 따라 접선 강성이 변하며 생기는 에너지 (선형 모델에서는 0) |

소산은 **힘 법칙에 쓰인 것과 같은 상대 속도**로 계산합니다. 그래서 벽 속도를 빠뜨리는 버그가 있으면 수지가 맞지 않습니다.
실제로 그 버그를 일부러 넣어 보면 잔차가 주입 에너지의 약 220%가 되고, dt를 줄여도 줄지 않습니다. 버그가 없으면 잔차는 0.3% 이하이고, dt를 줄이면 함께 줄어듭니다.

### 공기 저항을 넣지 않는 이유

지름 6 mm, 0.12 g 입자가 1.4 m/s로 움직일 때 항력은 `½ ρ C_d A v² ≈ ½·1.2·0.47·2.8e-5·1.4² ≈ 1.6e-5 N`입니다.
무게(1.2e-3 N)의 약 1.3%라서 무시합니다.

## 검증 테스트

```bash
pytest            # 기본 (느린 테스트 제외, 약 40초)
pytest -m slow    # 느린 테스트 (이후 단계에서 추가: 실제 강성, 상전이 스윕)
```

| 테스트 | 통과 기준 |
|---|---|
| 반발계수 조회표 왕복 | e = 0.1~0.99에서 0.2% 이내 |
| 바닥 낙하 반발 (선형/Hertz) | e = 0.3, 0.6, 0.9 각각 5% 이내 |
| 두 입자 정면 충돌 | 운동량 보존(1e-12), 반발 5% 이내, 손실 에너지 = 기록된 소산 (2%) |
| 비스듬한 충돌 (마찰+회전) | 운동량·각운동량 보존(1e-9), 회전 발생, 에너지 증가 없음 |
| 완전 탄성 다체계 (e=1, μ=0) | 2초간 총 에너지 변화 0.5% 이내 |
| 바닥에 놓인 입자 | 가라앉거나 튀지 않음 (변위 0.1 μm 미만) |
| 가진 중 에너지 수지 (마찰/회전 on·off, Hertz) | 잔차 1% 이내 |
| 에너지 수지 dt 수렴 | dt 절반에서 잔차 감소 |
| 겹침량 | N = 300, Γ ≈ 6.5에서 최대 겹침 < 지름의 5% |
| dt 수렴 (집단 상태) | dt 절반에서 평균 운동에너지 10%, 층 높이 3% 이내 (3개 시드 평균) |
| 고립된 이체 충돌 | 정확히 이벤트 1개, impact, 충격량 = 운동량 변화 (1e-9) |
| 공 튀기기 | 첫 충돌 시각·속도 0.1% 이내, 충돌 사이 비행 시간 = 2v/g (1%), 마지막 정지 접촉은 sustained |
| 바닥에 놓인 입자 | 이벤트 1개, sustained, 충격량 = 무게 × 시간 (0.1%) |
| 떨림 접촉 병합 / 별개 충돌 분리 | 인위적 떨림은 하나로 병합, 멀거나 빠른 재충돌은 분리 |
| 벽 힘 적분 = 이벤트 충격량 | 벽별로 상대 오차 1e-9 |
| 이벤트 충격량 = 운동량 변화 | μ = 0에서 벽 충격량 + 중력 = 전체 운동량 변화 (1e-9) |
| 이벤트 수, 조건 (b) | 입자당 주기당 충돌 수가 타당한 범위, 충돌 간격 ≫ 접촉 시간 |
| 분류 민감도 | v_impact↑ → impact↓, duration_max↑ → impact↑ (단조) |

## 개발 메모

Numba 디스크 캐시(`cache=True`)는 **다른 파일에 정의된 함수가 바뀐 것을 감지하지 못합니다.**
