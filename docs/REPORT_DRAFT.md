## 국문 초록 (초안)

1차 연구는 같은 비비탄을 담은 용기를 수직으로 흔들 때 나는 소리로 입자 개수를 추정했다 (웨이블릿 스케일로그램 CNN, 평균 절대오차 2.2개). 그러나 이 방법은 입자의 물성을 이미 안다는 전제에서만 성립한다. 소리는 개수와 물성(지름, 질량, 반발계수)의 조합에 반응하기 때문에, 물성이 바뀌면 "작은 입자 여러 개"와 "큰 입자 몇 개"가 비슷하게 들릴 수 있다.

본 연구는 **입력은 소리뿐이고 물성은 모르는 상태에서** 개수와 물성을 함께 추정하는 것을 목표로 한다. 물성을 연속적으로 바꾸며 정확한 라벨을 붙인 실험 데이터를 대량으로 얻을 수 없으므로, 3차원 이산요소법(DEM) 동역학과 충돌음 합성으로 이루어진 물리 시뮬레이터를 만들고, 1차 연구의 실제 녹음으로 시뮬레이터를 보정했다. 보정 과정에서 (1) 실제 가진 속도가 녹음마다 6.04~6.64 Hz로 달랐고, (2) 입자끼리의 충돌은 거의 탄성적(e ≈ 0.95)인 반면 입자-벽 충돌은 손실이 크다(e ≈ 0.7)는 것을 찾았다. 물성을 무작위로 바꾼 시뮬레이션 데이터 약 2만 클립으로 개수·물성 동시 추정 모델을 학습하고, 물성을 알려 줄 때와 모를 때, 여러 가진 속도를 함께 쓸 때를 비교했다. 【결과 대기: 블라인드 모델의 시뮬레이션·처음 보는 물질·실측 오차, 물성을 알려 줬을 때의 개선, 다중 조건 모델의 효과를 한두 문장으로】

주제어: 진동 음향 신호, 개수 추정, 수직 가진 과립계, 이산요소법, 시뮬레이션-실측 차이(sim2real), 도메인 무작위화

## 1. 서론

### 1.1 1차 연구와 그 한계
- 1차 연구는 5×5×7 cm 아크릴 상자에 같은 비비탄을 0~100개 넣고 크랭크식 가진기로 흔든 소리를 녹음해, (물리) 상전이 임계 가속도 Γc(N)의 개수 의존성과 (AI) 스펙트로그램 CNN으로 개수를 추정했다.
- 한계 1 — **물성 고정**: 학습·평가가 모두 같은 비비탄이다. 1차 연구의 스케일링 S_c = K(εF)², ε = 1 − e², F = N d²/A에서 보듯 소리를 바꾸는 것은 N 단독이 아니라 N과 물성(e, d)의 조합이다.
- 한계 2 — **음량 의존**: 1차 CNN의 물리 특징 5개 중 4개가 절대 음량에 묶여 있어, 입자 질량이나 마이크 거리만 바뀌어도 값이 이동한다.
- 한계 3 — **데이터 비용**: 개수 21가지 × 15회 녹음도 많은 노력이 든다. 물성까지 바꾸려면 입자 종류마다 이를 반복해야 한다.

### 1.2 연구 목표와 질문
- 목표: 소리만 듣고, 물성을 모르는 채로 **개수 N**과 **물성**(지름, 밀도·질량, 입자끼리/입자-벽 반발계수, 마찰계수, 탄성률)을 함께 추정한다.
- 연구 질문
  1. 물성을 모르면 개수 추정이 얼마나 어려워지는가? (이론 하한과 실제 모델)
  2. 물성을 알려 주면(지름·무게만, 또는 전부) 얼마나 좋아지는가?
  3. 여러 가진 속도의 소리를 함께 쓰면 개수와 물성의 혼동이 풀리는가?
  4. 시뮬레이션으로만 학습한 모델이 실제 녹음에 통하는가? 통하게 하려면 무엇이 필요한가?
  5. 어떤 소리 성분이 개수를 가르는가?

## 2. 이론적 배경 (1차 연구 2장에 추가할 내용)

### 2.1 이산요소법(DEM)과 접촉 모델
- 입자 하나하나의 운동방정식을 시간 적분한다. 접촉은 겹침 δ에 대한 힘으로 다룬다.
- **Hertz 접촉**: F_n = k_h δ^{3/2}, k_h = (4/3) E* √R_eff (E* 유효 탄성률, R_eff 유효 반지름). 충돌 시간 τ_c ∝ (m_eff² / (E*² R_eff v))^{1/5}.
- **반발계수와 감쇠**: 법선 감쇠력을 더해 에너지를 잃게 한다. Tsuji 감쇠(c ∝ δ^{1/4})는 반발계수가 충돌 속도와 무관하고, 점탄성(Kuwabara–Kono, Brilliantov) 감쇠(F_d = (3/2) A k_h δ^{1/2} δ̇)는 느린 충돌일수록 반발계수가 1에 가까워진다.
- **마찰과 회전**: Cundall–Strack 접선 스프링 + 쿨롱 마찰 한계.

### 2.2 충돌음이 마이크에 도달하기까지
소리 = (충돌 힘) ⊛ (용기·방·마이크의 응답) + 모터 잡음, 이후 마이크 게인과 클리핑.
- 충돌 하나의 힘은 폭 τ_c의 펄스이다. 스펙트럼은 약 1/τ_c까지 평탄하고 그 위에서 떨어진다 (수 mm 플라스틱 구슬: τ_c ≈ 50~70 μs → 16~24 kHz 대역을 6~15 dB 깎음). 즉 **물성은 펄스의 세기(질량·속도)와 고음 끝(탄성률·크기)에 나타난다.**
- 음색의 대부분은 용기(아크릴 상자의 판 진동, 9~10 kHz)와 방에서 온다. 그래서 같은 상자에서는 이 부분을 실측에서 측정해 쓸 수 있다.

### 2.3 식별 가능성과 크라메르-라오 하한
- 관측 통계 x가 (N, θ)에 의존할 때, 물성 θ를 모르면 N에 대한 피셔 정보에서 θ와 겹치는 부분이 빠진다 (방해 모수). 크라메르-라오 하한 σ_N ≥ √[(I⁻¹)_NN]로 "물성을 모르면 이론적으로 얼마나 나빠지는가"를 학습 없이 잴 수 있다.
- 여러 가진 조건에서 관측하면 θ와 N이 소리를 바꾸는 "방향"이 조건마다 달라져, 겹침이 줄어든다.

### 2.4 시뮬레이션-실측 차이(sim2real)를 줄이는 학습 기법
- **도메인 무작위화**: 확실하지 않은 조건(마이크 게인, 잔향, 잡음, 충돌별 방사 효율 등)을 넓게 바꿔 학습하면, 모델이 특정 합성 디테일에 기대지 못한다 (Tobin et al., 2017).
- **도메인 적대 학습(DANN)**: 라벨 없는 실측 녹음을 함께 넣고, 내부 표현으로 실측/합성을 구별하지 못하게 학습한다 (Ganin et al., 2016).
- **Conformal 예측**: 검증 데이터로 오차 분포를 보정해 "90% 확률로 이 구간 안"이라는 구간을 준다.

## 3. 연구 과정

### 3.1 실험 장치와 실측 녹음 (1차 연구 데이터 재분석)
- 상자 5×5×7 cm 아크릴, 크랭크식 수직 가진기 (진폭 1.34 cm), 휴대폰 녹음 48 kHz, 상자에서 약 2.7 m.
- 비비탄: 속이 꽉 찬 균일한 BB. **【확인 필요: 지름과 개당 질량. 본 연구 시뮬레이션은 6 mm, 0.12 g을 썼다 — 1차 연구 논문에는 적혀 있지 않다】**
- 녹음: N = 0, 5, …, 100 (21가지) × 15회, 각 약 7초.

재분석으로 알아낸 것 (`docs/RESEARCH_NOTES.md` 2절):

| 항목 | 값 |
|---|---|
| 가진 주파수 | 공칭 6.2 Hz (372 rpm, Γ ≈ 2.07) — **그러나 클립마다 6.04~6.64 Hz** (3.3절) |
| 에너지 분포 | 대부분 8~24 kHz, 용기 모드 9~10 kHz (1차 CNN의 22.05 kHz 리샘플은 11~24 kHz를 버림) |
| 클리핑 | N=50에서 표본의 5%, N=100에서 11%가 포화 |
| 울림 감쇠 | τ ≈ 62 ms |
| 모터 잡음 | 빈 상자 RMS 0.016 (N=5 충돌음의 약 1/10) |

### 3.2 시뮬레이터 (`foggyjupiter/2-2-rne-simulation`)
**동역학**
- 3차원 DEM, Hertz 접촉 (탄성률 ×0.25로 완화 — 강성 수렴 테스트에서 실제 강성 대비 모든 조건 12% 이내로 통과한 가장 무른 값), 쿨롱 마찰과 회전, 움직이는 벽(벽 속도 반영).
- 검증: 에너지 수지 잔차 1% 이내, 운동량 보존, 반발계수 재현, dt 수렴 등 테스트 82개.
- **바닥·천장 미세 요철**: 입자가 적을 때 모든 입자가 똑같이 위아래로만 튀는 비현실적 대칭(N=5~50에서 입자끼리 충돌 0회)이 있어, 고정된 무작위 요철 h(x, y)를 보존력으로 넣어 깼다 (에너지 기록 유지).
- 옵션(기본 꺼짐, 실측 비교용): 점탄성 반발계수, 크랭크 운동의 2차 고조파.

**음향 합성**
- 벽에 걸리는 힘(1.5 kHz 이하) + 충돌마다 Hertz 펄스(1.5 kHz 이상, 실제 탄성률의 τ_c로 폭 계산)
- → 실측 녹음의 고립된 충돌음에서 측정한 응답 모델(직접음 + 울림 꼬리, τ = 62 ms)과 1/3 옥타브 등화기
- → 실측 빈 상자 모터 잡음 → 마이크 게인·클리핑 → 48 kHz wav
- 동역학 결과(충돌 목록, 벽 힘)를 저장하므로 **소리만 몇 초 만에 다시 합성**할 수 있다 (`gransim render`, `gransim rerender`).

### 3.3 실측 녹음으로 시뮬레이터 보정 (sim2real)
같은 N(5~100), 같은 속도에서 합성음과 실측(개수별 15개)의 통계(음량, 클리핑, 대역 레벨, 스펙트럼 무게중심, 첨도 ψ3, 검출 충돌 수, 주기성)를 비교했다 (`results/sim2real/`).

**보정한 값** (모두 N과 무관한 단일 값 → 실제에 없는 개수 단서를 만들지 않음): 마이크 게인 0.92, 직접음/잔향 비 6, 등화기, 500 Hz 고역통과.

**발견 1 — 실제 가진 속도는 녹음마다 다르다** (그림 `results/figures/fig_shake_speed.png`)
- 소리의 에너지 포락선에서 클립마다 가진 주파수를 추정하면 6.04~6.64 Hz이고, N = 95·100은 약 6.5 Hz로 5% 빠르다.
- 5초 클립을 3%만 틀린 주파수로 접어도 주기 구조가 완전히 뭉개진다. 6.2 Hz로 고정해 계산했을 때 N = 100의 실측 주기성은 1.21로 나왔지만, 클립별 주파수로는 2.11이었다. 이 분석 오류 때문에 처음에는 "시뮬레이션이 높은 N에서 너무 주기적"이라고 잘못 판단했다.
- 조치: 시뮬레이터 분석과 학습 특징 모두 클립마다 주파수를 추정해 쓴다. 다중 rpm 데이터에는 ±4% 속도 오차를 넣었다.
- 시사점: 1차 연구 CNN이 N = 95·100에서 이 속도 차이를 단서로 썼을 가능성이 있다. 실험 Γ도 무부하 회전수에서 환산했다면 부하에 따라 달라졌을 수 있다.

**발견 2 — 입자끼리는 거의 탄성, 입자-벽은 손실이 크다** (그림 `results/figures/fig_restitution_probe.png`, 수치 `results/sim2real/restitution_probe/`)

| 시험한 설정 (BB, 372 rpm) | 주기성 오차 | 음량 오차 | 판정 |
|---|---|---|---|
| e = 0.8 (둘 다; 처음 기본값) | 0.86 | 0.068 | 낮은 N에서 동기화가 너무 약함 |
| e = 0.5, 0.65 | 1.07~1.25 | 0.13~0.16 | 기각 (높은 N 주기성 4~5) |
| e = 0.9, 0.95 | 0.86~1.24 | 0.044~0.054 | 높은 N은 맞고 낮은 N은 어긋남 |
| **e_pp 0.95, e_pw 0.7** | **0.44** | **0.035** | 가장 잘 맞음 (마이크 게인 0.92 그대로) |
| 점탄성 e(0.5 m/s) = 0.9 / 0.7 | 0.66 | 0.040 | 첨도는 가장 잘 맞으나 낮은 N 주기성 부족 |
| 크랭크 운동 (λ = 0.15, 0.3) | 0.68~0.84 | 0.032~0.033 | N 10~35 차이를 줄이지 못함 |

- 해석: BB끼리는 같은 플라스틱이고, 벽 충돌은 아크릴 상자와 가진 장치를 진동시키며 에너지를 잃는 것으로 볼 수 있다.
- 그 밖에 시험한 것: 충돌마다 방사 효율이 다르다(로그정규 σ ≈ 0.6~1.2에서 첨도·음량 개선 → 데이터에서 무작위화), 벽 위치별 방사 효율(기각), 충돌음 상승 시간(작은 효과), 휴대폰 리미터(기각: 실측처럼 11% 클리핑이 생길 수 없음), Γ가 더 높음(기각).
- **남은 차이**: N = 10~35에서 시뮬레이션의 검출 충돌 수가 3~5배 많다. 실측에서는 충돌이 한 위상에 몰려 하나로 들리는데, 위의 어떤 설정으로도 줄지 않았다. 상자의 흔들림이나 입자 모양 같은 다른 원인을 슬로모션 촬영으로 확인해야 한다 (`docs/RECORDING_PROTOCOL.md`).

| v1 | 372 rpm, 물성 전부 무작위 | 실행 1600 (대조 쌍 400 포함) × 녹음 조건 4 = 6400 클립 | 블라인드 학습·평가 |
| v1_r2 | v1과 같은 동역학, 충돌별 방사 효율 σ 0~1.5로 소리만 재합성 | 6400 클립 | 음향 도메인 무작위화의 효과 |
| bb_fixed | BB 크기·무게 고정, 측정 안 된 물성은 보정 범위에서 무작위 (e_pp 0.85~0.97, e_pw 0.6~0.85, μ 0.2~0.4, 355~400 rpm) | 300 × 4 = 1200 클립 | 1차 연구식 "물질을 아는" 모델 |
| v2 (multi_rpm) | 시스템 440개 × 300/372/450/550/650 rpm (Γ 1.35~6.3, 각 ±4% 속도 오차) | 2200 × 3 = 6600 클립 | 다중 조건으로 혼동 풀기 |

- 블라인드 물성 범위: 지름 4~8 mm, 밀도 1000~4000 kg/m³ (질량 = ρπd³/6, 6 mm에서 0.11~0.45 g), 반발계수 0.55~0.92 (v2 입자끼리는 0.97까지), 마찰 0.1~0.5, 탄성률 1.5~5 GPa. 실제로 구해서 녹음해 볼 수 있는 입자(무게가 다른 6 mm BB, 8 mm BB, 플라스틱·유리 구슬)를 포함하도록 정했다.
- 녹음 조건(마이크 게인 ±3 dB, 잔향, 잡음 0.5~1.5배)은 클립마다 무작위.
- 대조 쌍: 같은 N·다른 물성, 같은 물성·다른 N.
- 분할: 실행(다중 조건은 시스템) 단위 80/10/10. 밀도 2800~4000이면서 입자-벽 e 0.55~0.68인 영역은 학습에서 빼서 "처음 보는 물질(OOD)" 시험에 쓴다.

### 3.5 식별 가능성 분석 (학습 없이)
요약 통계 13개로 (1) 선형 회귀 하한, (2) 분산 분해, (3) 크라메르-라오 하한을 계산했다 (`gransim identifiability`).

### 3.6 학습 모델 (`foggyjupiter/RNE_Machine_Learning`)
- 입력: 48 kHz 로그-멜 128밴드(24 kHz까지, 고정 dB 기준) + 물리 특징 220개 (1차 연구식 12개, **클립별 가진 주파수 기준** 변조 스펙트럼 192개, 대역별 스펙트럴 첨도 16개).
- 전처리 비교: 모터 잡음 스펙트럼 차감, HPSS(타격 성분 = 충돌 클릭 / 조화 성분 = 용기 울림·모터 험), 22 kHz 리샘플(1차 연구 방식), 웨이블릿, 8 kHz 이상 대역만.
- 모델: CNN + 통계 풀링 + 물리 특징 융합(1차 연구 구조 계승) → N과 물성 8개를 각각 평균 ± 불확도로 출력.
- 개수 출력 방식 비교: 회귀 / 분류 / 소프트 라벨 / CORAL(순서형).
- 손실: Huber(N), 물성 오차, 가우시안 음의 로그우도(불확도), 같은 N 쌍 불변성, 같은 물성 쌍 순위, DANN.
- 다중 조건 모델: 속도별 소리를 같은 인코더로 처리하고 공칭 Γ를 임베딩해 더한 뒤 집합으로 통합. 집합 단위 음량 정규화로 질량·마이크 게인의 곱셈 효과를 구조적으로 제거.

### 3.7 평가 방법
- 시뮬레이션 test(같은 물성 분포의 새 실행), OOD(처음 보는 물성 영역), 물성 외삽·구멍, 개수 외삽.
- **실측**: 1차 연구 녹음. 선택·적응에 쓴 클립(개수별 1~5번)은 점수에서 뺀다.
- 지표: MAE, ±5개 이내 비율, 90% 구간 포함률(conformal), 물성 R², 축퇴 진단(N 오차와 지름 오차의 상관), **실측 오차가 가진 속도를 따라가는지**(같은 N 안에서 1 Hz당 개수 기울기), 시드 반복과 짝지은 검정.

### 4.1 시뮬레이터 검증
- 강성 수렴: Hertz 탄성률 ×1/4에서 충돌 충격량·위상별 에너지·상 지표가 실제 강성 대비 12% 이내 (선형 모델과 더 무른 Hertz는 탈락).
- Γc(N) (요철 도입 전, e = 0.8): 개수가 늘면 Γc가 커지는 **경향은 1차 연구와 일치**하나 값은 N ≥ 250에서 크게 낮다.

## 5. 결론 및 논의 (초안)

- 물성을 모르면 개수 추정의 이론 하한이 단일 조건에서 약 2배 나빠지고, 이 혼동은 실제 모델에서도 "작은 입자 여러 개 vs 큰 입자 몇 개"로 나타났다.
- 시뮬레이터를 실측으로 보정하는 과정 자체가 실험계에 대한 새로운 사실을 알려 줬다: 가진 속도가 녹음마다 최대 10% 범위로 달랐고, 입자끼리와 입자-벽의 반발계수가 크게 다르다.
- 【결과 대기: 물성을 알려 줄 때의 개선 폭, 다중 조건의 효과, 실측 성능에 대한 결론】

**한계**
- 실측 검증은 한 가지 입자(BB)뿐이다. 다른 물질에서 실제로 통하는지는 다른 입자의 녹음이 있어야 확인할 수 있다.
- 시뮬레이션이 N = 10~35에서 검출 충돌 수를 3~5배 많게 낸다.
- 용기 응답은 N과 무관하고(N별 측정 없음), 용기는 하나, 입자는 단분산이다.
- v1(주 데이터)의 벽 요철은 1~4°로, 나중에 보정에서 가장 잘 맞은 0.3~0.7°보다 크다. 반발계수 범위도 보정에서 찾은 e_pp ≈ 0.95보다 위를 덮지 않는다 (bb_fixed·v2는 반영).
- 시뮬레이션 강성은 실제의 1/4 (수렴 테스트로 정당화).

**후속 연구** (`docs/RECORDING_PROTOCOL.md`)
1. 다른 입자로 녹음 → 물질을 모르는 추정의 진짜 시험
2. 같은 상자를 여러 rpm으로 녹음 → 다중 조건 모델의 실측 검증
3. 단일 입자 낙하(벽 위·BB 위) → 반발계수 직접 측정, 실제 충돌음을 합성에 사용
4. 녹음마다 rpm 기록, 슬로모션 촬영 → 남은 차이의 원인
