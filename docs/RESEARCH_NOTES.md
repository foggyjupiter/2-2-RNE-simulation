# 2차 연구 연구 노트 — 물질을 몰라도 충돌음으로 개수와 물성 추정하기

보고서 작성용으로, 지금까지의 설계 판단·측정·발견·실험 계획을 근거와 함께 모았습니다.
수치 중 "예비"라고 표시한 것은 데이터 생성 도중(실행 약 300~500회)에 얻은 값이라, 최종 데이터로 다시 확인해야 합니다.

- 시뮬레이터: 이 레포 (`foggyjupiter/2-2-rne-simulation`)
- 학습 코드: `foggyjupiter/rne_machine_learning`
- 데이터셋: Hugging Face `FoggyJupiter/rne-granular-acoustics` (루트 = v1, `bb_fixed/`, `multi_rpm/`)

## 1. 문제 설정

1차 연구는 같은 BB탄·같은 용기·같은 가진 조건에서 개수를 추정했다 (물리 분석: Γc(N) 역산, CNN: MAE 2.2개).
이 결과는 **물질의 물성을 이미 안다는 전제**에서만 성립한다.

- 1차 연구의 스케일링 S_c = K(εF)², ε = 1 − e² 에서 보듯, 소리는 개수 N과 물성(반발계수 e, 지름 d가 들어간 층 수 F = Nd²/A)의 **조합**에 반응한다.
- 그래서 "반발계수가 낮은 입자 많이"와 "높은 입자 적게", "작은 입자 여러 개"와 "큰 입자 몇 개"가 비슷하게 들릴 수 있다 (축퇴).
- 1차 CNN의 물리 특징 5개 중 4개는 절대 음량에 묶여 있어, 질량이나 마이크 거리만 바뀌어도 이동한다.

**목표**: 입력은 소리뿐, 물성은 모르는 상태에서 N을 추정하고, 물성(지름, 밀도·질량, 반발계수, 마찰, 탄성률)도 함께 추정한다.
**방법**: 실험으로는 물성을 연속적으로 바꾸며 정확한 라벨을 붙일 수 없으므로, 물리 시뮬레이터로 데이터를 만들어 학습하고 1차 연구 실측 녹음으로 검증한다.

## 2. 실측 녹음에서 알아낸 것 (1차 연구 녹음 재분석)

| 항목 | 값 | 근거 |
|---|---|---|
| 가진 주파수 | **6.2 Hz (372 rpm)** | 고역 포락선 스펙트럼의 피크, 개수별 15개 클립 중앙값 |
| Γ | 2.07 (진폭 1.34 cm 가정) | Γ = A(2πf)²/g |
| 원본 표본화 | 48 kHz (1차 CNN은 22.05 kHz로 리샘플) | wav 헤더 |
| 에너지 분포 | 대부분 **8~24 kHz**, 용기 모드 9~10 kHz | 대역 레벨 |
| 클리핑 | N=50: 5%, N=100: 11% 표본 포화 | 진폭 ±1 비율 |
| 울림 감쇠 | τ ≈ 62 ms (RT60 ≈ 0.4~0.7 s, 방 잔향 + 용기 모드) | 주기 사이 꼬리의 포락선 적합 |
| 모터 잡음 | 빈 용기 RMS 0.016 (N=5 충돌음의 약 1/10) | N=0 클립 |

→ 1차 CNN은 리샘플로 11~24 kHz(에너지 대부분)를 버렸다. 음량 단서의 일부는 클리핑에 묻혀 있다.

## 3. 시뮬레이터 (요약; 세부는 README)

- **동역학**: 3차원 DEM, Hertz 접촉(탄성률 ×0.25, 강성 수렴 테스트 통과), 쿨롱 마찰+회전, 움직이는 벽(벽 속도 반영), 에너지 수지 잔차 < 1%.
- **추가한 모델 — 바닥·천장 미세 요철**: 입자가 적으면(N ≲ 60) 모든 입자가 똑같이 위아래로만 튀는 비현실적 대칭이 있었다 (N=5, 20, 50에서 입자-입자 충돌 0회). 고정된 무작위 요철 h(x, y)를 두고 보존력 fn·(−h_x, −h_y, ±1)로 처리해, 에너지·운동량 기록을 그대로 유지하면서 대칭을 깼다.
- **음향**: 벽 힘(저역) + 충돌 펄스(고역, 실제 물성의 Hertz 접촉 시간 τ_c) → 실측 응답 통계(직접음 + 꼬리) → 실측 모터 잡음 → 마이크 게인·클리핑, 48 kHz.
- **접촉 시간 분리**: 충격량은 동역학(완화 강성)에서, 펄스 폭은 실제 탄성률로 계산. 48 kHz에서 τ_c ≈ 50~65 μs가 16~24 kHz를 6~15 dB 깎으므로 음색에 드러난다.

## 4. 실측 대비 보정과 남은 차이 (sim2real)

같은 N(5~100)·같은 rpm에서 합성음과 실측(개수별 15개)의 통계를 비교했다 (`results/sim2real/`).

**보정한 값** (모두 N과 무관한 단일 값 → 실제에 없는 개수 단서를 만들지 않음)
- 마이크 게인 0.92, 직접음/잔향 비 6, 1/3옥타브 EQ, 방사·마이크 고역통과 500 Hz

**맞는 것**: N에 따른 음량 증가(로그 RMS 오차 0.05), 클리핑 비율, 스펙트럼 무게중심, 4 kHz 이상 대역, 첨도 ψ3 (N ≤ 50)

**중요한 수정 — 실측 가진 속도는 클립마다 다르다.** 소리의 에너지 포락선에서 클립마다 가진 주파수를 추정하면 6.04~6.64 Hz이고 (공칭 6.2 Hz), N = 95·100 녹음은 약 6.5 Hz로 5 % 빠르다. 5초 클립을 3 %만 틀린 주파수로 접어도 주기 구조가 다 뭉개지므로, 6.2 Hz로 고정해 계산한 실측 "주기성"은 틀린 값이었다 (N=100: 1.21 → 클립별 주파수로 2.11). 이전에 적은 "N=100에서 시뮬레이션 주기성 과다"는 대부분 이 분석 오류였다. 이제 `sim2real`과 `rneml`의 모든 주기 관련 특징(접은 에너지, 변조 스펙트럼, 성분 분석)이 클립마다 추정한 주파수를 쓴다. (1차 연구 CNN이 N=95·100에서 이 속도 차이를 단서로 썼을 가능성도 있다.)

수정한 지표로 다시 보면 실측 주기성은 N이 늘수록 줄어든다 (N=5: 4.4, 20: 3.2, 50: 2.5, 100: 2.1). e = 0.8 시뮬레이션은 N과 무관하게 약 2 → **낮은 N에서는 덜 동기화**, 높은 N에서는 약간 과함.

**검증한 가설** (수정한 지표, `runs/e_probe/egrid*.json`; 게인은 매번 다시 보정)

| 가설 | 시험 | 결과 |
|---|---|---|
| 실제 반발계수가 더 낮다 (e = 0.5, 0.65) | 동역학 재실행 | 기각: 낮은 N 주기성은 나아지나 N ≥ 35에서 주기성 4~5 (실측 2.1~2.6), 첨도·음량 증가가 크게 어긋남 |
| 둘 다 더 높다 (e = 0.9, 0.95) | 동역학 재실행 | 반만 맞음: N=100 검출 충돌 수 19.6 → 1.9 (실측 2.3), 대신 N=5~20 주기성이 더 약해짐 |
| **입자-입자는 거의 탄성, 입자-벽은 손실 큼 (e_pp 0.95, e_pw 0.7)** | 동역학 재실행 | **가장 잘 맞음**: 주기성 오차 0.86 → 0.44 (N=5: 4.55 vs 실측 4.36, N=100: 2.33 vs 2.11), 첨도 N=100 −0.30 vs −0.47, 음량 오차 0.068 → 0.035, 게인 0.92 그대로. BB끼리는 같은 플라스틱, 벽 충돌은 아크릴 상자·가진 장치가 진동하며 에너지를 가져가므로 그럴듯함 |
| 속도에 따라 변하는 반발계수 (점탄성 Hertz, e(0.5 m/s) = 0.9/0.7) | 새 접촉 모델 (`contact.restitution_law: viscoelastic`) | 첨도는 가장 잘 맞으나 (0.08) N=5 주기성 3.0 → 위 일정값 분리보다 낫지 않음. 옵션으로 남김 |
| 실제 Γ가 더 높다 (진폭 불확실; Γ = 3, 4) | 동역학 재실행 | 기각: 음량 오차는 줄지만 충돌 수·주기성 그대로 |
| 크랭크 구동이라 운동이 순수 사인이 아니다 (λ = r/l = 0.15, 0.3; e_pp 0.95/e_pw 0.7과 함께) | 새 옵션 `excitation.crank_ratio` | 기각: N=20 검출 충돌 수 135 (실측 27)·주기성 1.97 (3.24) 그대로, N=5 주기성은 오히려 낮아짐. 옵션으로만 남김 |
| 요철이 너무 크다 (0.3°, 0.7° vs 2°) | 동역학 재실행 | 부분 개선 (N=5 주기성 2.1 → 2.8) → 이후 데이터에 0.3~2° 적용 |
| 충돌마다 방사 효율이 다르다 (로그정규 σ) | 음향만 재합성 | σ ≈ 0.6~1.2에서 첨도·음량·고주파 포락선 분포 개선, 높은 e에서는 N=100 검출 충돌 수를 늘림 → 데이터에서 σ 0~1.5 무작위 |
| 벽 위치에 따른 방사 효율 (판 모드 모양) | 음향만 재합성 | 기각: 음량·첨도 오차 증가 |
| 충돌음이 천천히 올라온다 (실측 상승 0.5 ms vs 0.2 ms) | 직접음에 상승 시간 0.1~0.4 ms | 작은 효과 (검출 충돌 수 로그 오차 1.32 → 1.16) |
| 휴대폰 AGC/리미터 | 기존 렌더에 압축기·look-ahead 리미터 | 기각: 리미터가 있으면 실측처럼 11% 클리핑이 생길 수 없음 |
| **합성 클릭의 모양이 실제와 다르다** | 충돌마다 실제 녹음된 BB 충돌음(N = 5·10 녹음의 고립 충돌)을 넣어 재합성 (`acoustics.impact_source: recorded`) | **크게 개선**: 검출 충돌 수 로그 오차 1.33 → 0.46 (N=50: 56 → 8.7, 실측 8.1; N=100: 13 → 1.1, 실측 2.3; N=20: 136 → 69, 실측 27), 통과율 0.73 → 0.82 (최고). 음량 증가 기울기는 조금 나빠짐 (오차 0.035 → 0.061) |

**아직 남은 차이**: 검출 충돌 수 차이의 대부분은 동역학이 아니라 **합성 클릭의 모양** 때문이었다 (실제 클릭은 천천히 올라오고 구조가 있어, 촘촘한 소리 속에서 15 dB 급상승으로 덜 잡힘). 실제 클릭을 써도 N = 20에서 2.6배가 남고, N = 10~35의 주기성이 약하다 (실측은 충돌이 한 위상에 몰림). 반발계수·요철·Γ·크랭크 운동으로는 줄지 않았으므로 상자의 흔들림(수평 성분)이나 입자 모양(완전한 구가 아님) 같은 다른 원인일 수 있다. 녹음 절차서의 슬로모션 촬영과 단일 입자 낙하가 이를 가를 것이다.

**데이터에 반영** (아직 만들지 않은 데이터만; v1은 진행 중이라 그대로):
- bb_fixed: BB의 모르는 물성을 고정(e=0.8)하지 않고 무작위 — e_pp 0.85~0.97, e_pw 0.6~0.85, 마찰 0.2~0.4, 가진 속도 355~400 rpm
- v2 (다중 rpm): e_pp 상한 0.97, 각 rpm에 ±4 % 속도 오차 (모델에는 공칭 Γ를 줌)
- 둘 다 + v1 재합성(`v1_r2`, 같은 동역학): 충돌별 방사 효율 σ 0~1.5 (음량 중립), 클립마다 합성 클릭 / 실제 BB 클릭을 반반 (실제 클릭 라이브러리는 실측 개수별 1~5번 클립에서만 잘라, 6~15번은 모든 실험의 실측 평가에 그대로 남김)

데이터에서는 게인 ±3 dB, DRR 3~12, 잡음 0.5~1.5배, 요철 범위로도 덮고, 학습에서는 비지도 실측 적응(DANN)으로 대응한다.

**ML 쪽 확인** (`rneml gap`, 예비): BB와 비슷한 시뮬레이션 대비 실측의 z 점수가 큰 특징 = 활성 프레임 비율, dB 표준편차, 주기성, 충돌 검출률.

## 6. 식별 가능성 — 물질을 모르면 얼마나 어려운가 (예비, 실행 약 330회)

학습 없이 요약 통계 13개로 측정 (`gransim identifiability`, `results/identifiability/`).

**선형 하한** (릿지, 실행 단위 교차검증): N MAE — 물질 모름 11.1 / 물질 앎 10.2 / 찍기 24.8.
물성: 지름 R² 0.54, 밀도 0.29, 반발계수 0.12~0.16, 마찰 ≈ 0.

**분산 분해**: 물성은 N만큼 소리 통계를 바꾸지만, 바꾸는 "방향"이 다르다.
음량·첨도·충돌률은 N과 물성이 둘 다 바꾸고, 무게중심·16 kHz 이상 대역은 거의 물성만 바꾼다 (N만으로 2~4%, N+물성으로 77%).
→ 모델이 고음 쪽에서 물질을 알아내 개수 단서를 보정할 수 있는 구조.

**크라메르-라오 하한** (N 오차 1σ, 요약 통계 13개):

| N | 물질 앎 | 물질 모름 |
|---|---|---|
| 1~19 | 2.2 | 4.3 |
| 20~49 | 9.5 | 16.2 |
| 50~79 | 14.7 | 32.3 |
| 80~100 | 17.0 | 38.2 |

→ 단일 조건에서는 물질을 모르면 이론 하한이 약 2배. N이 클수록 급격히 나빠짐(포화). 다중 조건(v2)의 동기.

## 7. 학습 모델 설계 (`rne_machine_learning`)

- 입력: 48 kHz 로그-멜(128밴드, 24 kHz까지, 고정 dB 기준) + 물리 특징 220개
  - 1차 연구식 12개 + **변조 스펙트럼** 192개(16대역 × 0.8~50 Hz; 가진 6.2 Hz와 배음, 음량·위상 무관) + **대역별 스펙트럴 첨도** 16개
- 전처리 옵션: 모터 잡음 스펙트럼 차감, **HPSS**(타격=충돌 클릭 / 조화=용기 울림·모터 험 채널 분리), 대역 집중, 웨이블릿, 22 kHz(1차 연구 방식)
- 모델: CNN + 통계 풀링 + 물리 특징 융합 (1차 연구 구조 계승) → **N과 물성 8개를 회귀**, 각각 평균 ± σ
- 손실: Huber(N), 물성 MSE, 가우시안 NLL(σ), 같은 N 쌍 불변성, 같은 물성 쌍 순위, 비지도 실측 적응(DANN)
- 다중 조건 모델: 조건별 공유 인코더 + Γ 임베딩 + 집합/순서형 통합 + 차분 경로 + 집합 단위 음량 정규화(per_set: 물성·게인의 곱셈 효과를 구조적으로 제거)
- 평가: 실행 단위 분할(누수 검사), 물성 외삽/구멍, 개수 외삽/희소 격자, conformal 90/95% 구간, 게인 교란, 개수 구간별, 시드 반복·짝지은 검정, **실측 녹음**
- 해석: 임베딩 PCA, 선형 프로빙(실제 상·질서 변수), 대역 마스킹, 축퇴 진단(N 오차 vs 지름 오차 상관)

## 8. 예비 결과 (데이터 약 500클립, CPU 짧은 학습 — 최종 아님)

**기준선** (같은 분할, N MAE):

| 기준선 | 시뮬레이션 test | 처음 보는 물질 | 실측 |
|---|---|---|---|
| 음량만 | 21.9 | 21.8 | **17.7** |
| 충돌 계수만 | 22.7 | 19.2 | 21.6 |
| 질서 변수 (ψ2, ψ3, 주기성) | 10.7 | 17.2 | 30.3 |
| 손특징 204개 릿지 | 10.8 | 12.7 | 35.5 |

→ **시뮬레이션에서 좋은 특징일수록 실측에서 나빠진다.** 실측으로 보정한 음량은 옮겨 가지만, 세밀한 특징(충돌률·주기성)은 sim2real 차이가 큰 바로 그 특징들이다.

**CNN 파일럿** (DANN 포함): test MAE 9.9, OOD 11.6, 실측 42.8 (+35 과대 추정).
물성 R²: 지름 0.62, 질량 0.57, 밀도 0.40, 입자끼리 반발계수 0.37.
**축퇴 진단**: N 오차와 지름 오차의 상관 −0.56 → "작은 입자 여러 개 vs 큰 입자 몇 개" 혼동이 실제로 일어난다.

**선형 프로빙** (파일럿 내부 표현에서 선형 복원 R²): 위상 집중도 0.94, 층 높이 분산 0.92, 층 높이 0.90, 집단성 0.89, N 0.79.
→ 개수만 맞히도록 학습했는데, 모델이 **고체상/유체상 같은 실제 상을 스스로 내부 변수로 갖게 됐다.** 1차 연구 물리 파트(상전이)와 AI 파트를 잇는 결과.

## 8.5 어떤 성분이 개수를 가르는가 (예비, `rne_machine_learning/results/components_prelim/`)

소리를 주파수 대역 16개 × 성분 유형 11가지로 나누고, 성분마다 세 가지를 쟀다: 시뮬레이션(물질 모름)에서의 정보량, 실측 녹음 안에서의 정보량, 시뮬레이션에서 배운 관계가 실측에 통하는지(이전).
실측 녹음은 개수별 1~5번만 선택에, 6~15번은 검증에만 썼다.

- **실측까지 통하는 개수 단서 = 8 kHz 이상 대역의 충격성(대역 첨도), 충돌 클릭 음량(HPSS 타격 성분), 20~50 Hz 변조 결.** 이전 R² 0.74~0.89.
- **시뮬레이션에만 있는 단서 = 가진 주기에 묶인 변조, 주기 접힘(ψ1), 충돌 검출률.** 시뮬레이션에서는 개수 정보가 있지만 실측으로 옮기면 R² < 0 (−0.08 ~ −1.5). sim2real 비교(4절)에서 어긋났던 바로 그 성분들.
- 2 kHz 이하 대역은 실측 안에서는 개수와 상관이 있지만 시뮬→실측 이전은 음수.
- **검증**: 통하는 성분 40개만 쓰면 실측 오차(부스팅, N MAE)가 17.2 → **9.0**으로 절반. 시뮬레이션 오차는 6.7 → 8.5로 조금 늘어난다. "시뮬레이션에서 가장 정확한 조합 ≠ 실측에서 가장 좋은 조합".
- 이 선택을 CNN에 적용한 실험(B9, B11 "8 kHz 이상 이미지 + 선택 성분", B12 + 실측 적응)을 실험 묶음에 넣었다.
- **주의 (나중에 발견)**: 이 예비 분석은 가진 주파수를 6.2 Hz로 고정했다. 실측은 클립마다 6.04~6.64 Hz라 "가진 주기에 묶인 변조"와 "주기 접힘"은 실측에서 일부러 뭉개진 상태였다 (4절). 이제 클립마다 주파수를 추정하므로(성분 캐시 v2), 이 두 성분이 정말 시뮬레이션에만 있는 단서인지는 전체 데이터로 다시 돌릴 때 확인한다.

## 10. 실측 검증을 위해 추가로 녹음하면 좋은 것 (자세한 절차: `docs/RECORDING_PROTOCOL.md`)

1. **같은 상자를 여러 rpm으로** (300/372/450/550/650 근처): 다중 조건 모델의 실측 검증. 개수 몇 개(예: 20, 50, 80)만으로도 의미 있음.
2. **빈 상자를 각 rpm에서** (모터 잡음 라이브러리; 지금은 372 rpm만 있어 다른 rpm은 재생 속도를 바꿔 근사).
3. **다른 입자**: 무게가 다른 6 mm BB(0.20, 0.25, 0.30 g), 8 mm BB, 유리·플라스틱 구슬 → 물질을 모르는 추정의 진짜 시험. 지름·무게는 재서 기록.
4. **N별 임펄스 응답**: 입자를 정지 상태로 넣고 상자를 가볍게 두드리기 (N = 0, 50, 100, …). 시뮬레이터의 응답은 지금 N과 무관하다.
5. **단일 입자 낙하**: 바닥에 BB 하나를 떨어뜨린 소리 → 실제 반발계수와 충돌음 하나의 모양 (sim2real 차이 진단에 직접 도움). sim2real은 "BB끼리 e ≈ 0.95, BB-아크릴 벽 e ≈ 0.7"을 가리키므로, 벽 위 낙하와 BB 위 낙하(바닥에 고정한 BB 위)를 따로 재면 이 가설을 바로 시험할 수 있다.
6. **가진 속도 기록과 슬로모션**: 실측 속도가 클립마다 ±5 % 달랐다. 녹음마다 rpm을 같이 기록하고(슬로모션 또는 소리), N = 20 정도에서 상자를 240 fps로 찍으면 남은 차이(N 10~35에서 실측은 충돌이 한 위상에 몰림)가 입자 운동 때문인지 가진 장치의 흔들림 때문인지 볼 수 있다.
