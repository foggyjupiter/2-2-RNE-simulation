## 해석
- 특징이 가장 비슷한 시뮬레이션 클립을 찾아도 블라인드 모델과 같은 모양의 편향이 나온다 (N 30~50 +18, N 80~100 −17). BB와 비슷한 물성으로만 찾아도 사라지지 않는다 → **물질 혼동이 아니라 소리 자체의 차이**: 합성음이 이 개수 범위의 실측 소리를 재현하지 못한다.
- 차이의 정체는 **가진 주기에 맞춘 소리의 주기성(위상 집중)이 N에 따라 변하는 모양**이다.
  - N 5~25: 실측은 소리가 켜져 있는 시간 비율(active_ratio)이 시뮬레이션보다 훨씬 낮고(−5.6σ), 고음 대역의 가진 주파수 성분(h1)이 강하다(+2σ) → 충돌이 한 위상에 몰린다.
  - N 30~50: 가진 주파수의 4배 성분(h4)이 강하다(+2σ) → 날카로운 주기 펄스.
  - N 80~100: 반대로 가진 주파수 성분이 약하다(−2.4~−3.5σ) → 시뮬레이션보다 덜 주기적이다.
  - 같은 비교표(`results/sim2real/comparison_table.txt`)의 주기 봉우리: N = 5에서 실측 4.4 vs 합성 2.1, N = 100에서 실측 2.1 vs 합성 2.6.
- 물리적 해석: 실제 BB는 적을 때 시뮬레이션보다 더 함께(동기화되어) 튀고, 많을 때는 더 빨리 흐트러진다. 1차 연구의 상전이 관점에서는 실제 계의 Γc(N)이 시뮬레이션과 다르다는 뜻일 수 있다 (4.1 참조).
- 모델 쪽: 같은 N 안에서는 15~23 kHz 대역 포락선의 빠른 질감 변조가 클수록 적게 센다 (상관 −0.46). 가진 속도 차이의 영향은 작다 (−0.13).
