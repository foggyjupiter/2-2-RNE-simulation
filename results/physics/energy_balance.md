# 에너지 수지로 본 상의 스케일링 (학습 없음)

## A. v3 (Γ ≈ 1.9~2.2, 물성 무작위, 실행 1580개): 한 변수 교차검증 R²

거듭제곱 법칙 맞춤 log θ = a − b·log(x) (선형 R²):

- 가장 단순한 기체 수지 x = ε_w + c·ε_pp·F: c = 3.00, b = 0.81 (이론 1), R² = 0.81
- 바닥 충돌이 층 수와 함께 느는 형태 x = ε_w(1 + kF) + c·ε_pp·F: k = 2, c = 2.75, b = 0.76, R² = 0.87
- 1차 연구 변수 x = ε̄F: b = 0.44, R² = 0.74

층 수 구간별 log θ vs log ε̄F 기울기 (R²): F 0~0.3: -0.07 (0.22), F 0.3~1: -0.63 (0.85), F 1~3: -0.83 (0.77)

비모수 한 변수 교차검증 R² (곡선 모양 자유):

| 지표 | N | F | ε̄F | 이론 ε_w(1+2F) + 2.75·ε_pp·F |
|---|---|---|---|---|
| 들뜸 θ = v²/(Aω)² | 0.54 | 0.82 | 0.94 | 0.94 |
| 위상 집중도 | 0.66 | 0.88 | 0.96 | 0.94 |
| 집단성 | 0.38 | 0.59 | 0.69 | 0.53 |
| 높이 분산 | 0.41 | 0.57 | 0.69 | 0.51 |
| 충돌 빈도/입자 | 0.74 | 0.96 | 0.78 | 0.64 |

입자당 충돌 빈도 × v/g = 2.01 + 0.95·F (R² 0.46) — 바닥 충돌(상수항)에 층 수에 비례하는 입자끼리 충돌이 더해진다.

## B. v2 (같은 시스템 × 5가지 속도): 입자 운동에너지 v² ∝ (Aω)^α, 시스템 안에서의 기울기
